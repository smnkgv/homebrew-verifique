# Homebrew tap for verifique

```bash
brew tap smnkgv/verifique
brew trust smnkgv/verifique
brew install verifique
```

It installs on Macs and on Linux, with ARM or Intel and AMD processors alike. Database support is an
add-on: install the ones your projects use with `verifique plugin add`, such as
`verifique plugin add postgres`. See [verifique](https://github.com/smnkgv/verifique).

The status-bar panel, signed and notarized, as a cask:

```bash
brew install --cask smnkgv/verifique/verifique-panel
```

Or install it with `verifique panel install`, which also opens it whenever you log in.
